# VPS 評測：從回程路由、跑分到套餐價格，教你用可查證的數據判斷一台 VPS 值不值得買

搜「VPS 評測」的人，通常已經看過三、四篇差不多的文章了。標題寫「實測」，內容卻只有一張 Geekbench 截圖，配一句「效能強悍」；講到線路就說「三網優化、晚高峰不掉速」，但沒有路由追蹤；價格表貼的是兩年前的數字，點進去看方案早就下架了。

看完之後你還是不知道該不該買。

問題不在評測本身，而在多數評測只回答「這台機器快不快」，沒有回答你真正在意的三件事：**晚高峰會不會掉速、跑分有沒有灌水、這個價格對不對得起它的配置**。這篇用 DMIT 這家主打 CN2 GIA 與 CMIN2 線路的服務商當實例，把一套可重複套用的檢查流程拆開來講。

## 一份能用的 VPS 評測，至少要回答這幾件事

跑分只佔其中一小角。真正會影響你每天使用體驗的，是下面這些：

**硬體世代要問到型號，不是只問核心數。** 同樣寫「4 vCPU」，AMD EPYC 7003 和 EPYC 9005 的單核性能可以差一整個世代。DMIT 在洛杉磯、香港的主力機型這幾年陸續從 AS3、AN4 換到 AN5（AMD EPYC 9005 平台），如果你看的評測還在貼 EPYC 7443P 的數據，那台機器可能已經不在售了。

**磁碟 I/O 比 CPU 更容易被忽略。** 資料庫、建站、跑容器都會卡在這裡。合理的 NVMe 機型大塊檔案讀寫應該在 900MB/s 以上，掉到 300～400MB/s 就要留意是不是共用盤吃得太兇。

**延遲要分電信、聯通、移動三家看。** 「全國平均 150ms」這種數字意義有限，因為同一台機器電信可能 84ms、移動卻 232ms。差異來自回程路由走的是 CN2 GIA、AS9929、CMIN2 還是普通 4837／cogent。

**IP 品質決定你能做什麼。** 原生 IP 還是廣播 IP、串流能不能解鎖、有沒有被列進黑名單資料庫，這些直接影響跨境電商、廣告投放、串流相關的使用場景。

**流量超量之後會發生什麼。** 這是評測最常漏掉、卻最容易讓人踩雷的一項。有些商家超量直接停機，有些限速到 4Mbps 繼續跑。DMIT 屬於後者，但不同系列的限速值差距很大，下面會列。

**換 IP 政策。** 做跨境業務的人大概都遇過 IP 被牆或被標記。換一次多少錢、多久能換一次、要不要人工審核，值得在下單前先看清楚。

## DMIT 是誰，三條線路先分清楚

DMIT 約 2017 年前後成立、在美國註冊，但營運團隊面向華語市場，提供中文客服，付款支援支付寶、微信支付、PayPal 和信用卡。機房分散在美國洛杉磯、中國香港、日本東京三地，全部走 KVM 虛擬化，硬體用 AMD EPYC 系列，官方對外說法是不超售，並標示 99% SLA。

對台灣或華語使用者來說，真正需要先搞懂的不是硬體，而是**線路分級**。DMIT 每個機房都切成三條線路，價格差可以到三倍以上，差別全在「回中國大陸的路怎麼走」：

這裡有個常見誤解要拆掉：T1 不是「便宜版的 Pro」。它便宜是因為沒有為中國大陸做任何優化，電信用戶買香港 T1，延遲有可能比買洛杉磯還高。它不是差，是定位不同。

## 第三方實測數據大概長什麼樣

公開的第三方測評可以提供一個量級參考（以下都是特定時間、特定節點的測試結果，換時段會有波動，不能當保證值）：

- **洛杉磯 EB，2 核 2G 方案**：AMD EPYC 平台，實測上傳約 500Mbps、下載約 580Mbps，三網平均延遲約 159ms，港澳台約 147ms；串流服務可解鎖，IP 判定為原生。
- **洛杉磯 T1.TINY**：硬碟平均讀寫約 948MB/s，本地上傳約 4275Mbps、下載約 2329Mbps，但三網平均延遲來到約 208ms，移動端更接近 255ms。硬體漂亮、回國路徑普通，正是 T1 的典型特徵。
- **東京 EB，1 核 2G 方案**：電信約 84ms、聯通約 80ms、港澳台低至 47ms，適合東亞區域的延遲敏感應用。
- **洛杉磯 AN5 EB.TINY**：Geekbench 6 單核跑分約 2650+，這個數字拿去直接建站也不吃力。

看這些數據的時候，記得對照自己的使用場景。如果你主要服務歐美用戶，那 208ms 的 T1 根本不是缺點；如果你的用戶在台灣、香港，東京節點的 47ms 才有意義。

## 評測文章很少提，但會決定你後不後悔的細節

**超量規則每個機房、每個系列都不一樣。** 洛杉磯 Pro 是限速 4Mbps 繼續跑，EB 大約 4～10Mbps，T1 寬鬆得多、從 100Mbps 到 1Gbps；香港 Pro 高階機種則是超量關機。同樣叫「DMIT」，處理方式可以完全不同，這件事比你 CPU 是 7003 還是 9005 更影響日常。

**換 IP 已改成自助操作，但審核規則有差。** 洛杉磯 Pro 與 EB 付費更換（約 $5）不需審核，免費更換要人工審核；全區 T1 只支援付費更換且需審核；香港與東京的 Pro、EB 無論免費或付費都要審核。審核通常 24 小時內完成，通過後你需要在 48 小時內確認，系統才會實際更換。

**庫存是這家最大的變數。** 熱門的低價機型長期處在缺貨—補貨—秒殺的循環裡。如果你需要的是特定機房加特定線路的組合，等貨是常態，不是例外。

**跨機房內網互通。** 香港、美國、日本之間可以透過內網傳資料，對需要多節點架構的人來說省下不少公網流量。

## 那到底該怎麼選

把決策拆成兩步，會比直接看價格表快很多。

**第一步，看你的用戶在哪個電信商。** 用戶以電信為主，Pro 的 CN2 GIA 值得那個價差；以移動為主，EB 的 CMIN2 回程性價比明顯更好；聯通用戶兩者都在 AS9929 上，差異不如電信那麼大。

**第二步，看你缺什麼資源。** 缺的是回國速度，選 Pro；缺的是流量和頻寬，選 EB 或 T1 VOLUME；缺的是純算力、用戶都在海外，選 T1 GENERAL。預算壓在 $10 以內，洛杉磯、香港、東京的 T1.TINY 都是 $6.90／月，WEE 方案則是 $36.90／年——這幾個是全系列門檻最低的選項，代價就是沒有大陸優化。

如果你只是想要一個乾淨、可預期、不會晚高峰突然崩掉的節點，Pro 的溢價是合理的；如果你拿來當中轉或跑國際服務，硬去買 Pro 就是把錢花在你不會用到的路由上。
